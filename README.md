# SEDELNIKOV — 3D & Motion Portfolio

Static portfolio: HTML, CSS and JavaScript. No build tools required.

## Publish
In repository Settings → Pages choose Deploy from a branch → main → / (root) → Save.

## Customize
- Edit name, biography and links in index.html.
- Replace the two decorative CSS studies with real project images or videos. They are explicitly labeled as design previews, not real case studies.
- Adjust colors in the :root variables in style.css.
- Google Fonts is optional; the site falls back to Arial when offline.

Motion respects prefers-reduced-motion. No analytics, forms, cookies or API keys are included.
