# Личный трекер

В разделе «Зал» выбери день в календаре и добавь тренировку. Укажи группы мышц и длительность, затем внеси упражнения и подходы. После сохранения новые упражнения появляются в каталоге. В общем календаре и таймлайне видны тренировки и заметки.

## Запуск на Windows

Установи Node.js 24 и запусти `START.cmd`. На ПК открой http://localhost:8788/. На телефоне в той же домашней Wi-Fi сети открой адрес из окна запуска. Оставь это окно открытым.

После обновления `main` закрой старый сервер и запусти `UPDATE-AND-START.cmd` из клона репозитория. Записи хранятся в локальном `tracker.sqlite`. Чтобы перенести записи из другой папки, останови серверы и скопируй файл базы. Старые отдельные подходы видны в календаре.

Локальный сервер читает интерфейс при каждом запросе. После сохранения правок интерфейса обнови страницу браузера.
